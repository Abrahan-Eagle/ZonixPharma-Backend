## Protocolo para cada aporte nuevo (EXT)

Todo informe, video, libro, conversación o salida de otra IA entra con un ID y se clasifica:

| Estado | Significado | Efecto |
|---|---|---|
| `MANTENER` | Compatible con fuentes/canon y útil para Zonix | Puede entrar al plan |
| `CORREGIR` | Tiene una idea útil, pero cifra, alcance o etiqueta es imprecisa | Entra solo la versión corregida |
| `DESCARTAR` | Contradice el modelo, la regulación o la evidencia | No se incorpora |
| `PENDIENTE HUMANO` | Requiere founder, abogado, contador, asesor regulatorio o dato de campo | No se presenta como decisión |

Para ser citable, el aporte debe incluir: texto completo; URLs directas y fecha; fuente primaria; fórmula y supuestos; jurisdicción; diferencia entre hecho, cálculo e inferencia.

Si faltan URLs, el aporte sirve como **pista de investigación**, no como fuente externa del data room.

Cuando el founder entregue otra salida:

1. asignar ID `EXT-00N`;  
2. conservar el texto íntegro fuera del data room;  
3. extraer afirmaciones y cálculos;  
4. contrastar contra fuentes primarias y pack v4;  
5. clasificar `MANTENER/CORREGIR/DESCARTAR/PENDIENTE HUMANO`;  
6. identificar qué carril y decisión afecta;  
7. actualizar solo el archivo de propósito afectado en esta carpeta;  
8. registrar nueva versión y fecha;  
9. no ejecutar outreach, pricing o contratos sin gate humano.

## Taxonomía de claims (Plan Integral §16 ↔ EXT)

Además del estado `MANTENER/CORREGIR/DESCARTAR/PENDIENTE HUMANO`, cada afirmación en pitch o memo interno puede llevar etiqueta de **tipo**:

| Etiqueta | Uso | Relación con EXT |
|---|---|---|
| `FACT` | Dato verificable (fuente primaria o registro interno) | EXT con URLs revalidadas o ledger propio |
| `CALC` | Resultado matemático reproducible (ej. 237.412/1.582.747) | Fórmula en el EXT o en pack |
| `ASSUMPTION` | Supuesto del modelo aún no validado en campo | No presentar como tracción |
| `INFERENCE` | Interpretación derivada de hechos | Explicitar la cadena |
| `CLAIM-3P` | Afirmación de un **tercero** (Carta, LAVCA, etc.) | Ficha EXT; **nunca** como resultado de Zonix |
| `LEGAL-REVIEW` | Requiere abogado | No dictamen en Captación |
| `ACCOUNTING-REVIEW` | Requiere contador | Prepago / reconocimiento de revenue |

Ejemplo: «10 farmacias activas» es `FACT` solo con registro; «100 farmacias en 12 meses» es `ASSUMPTION`. Research 2026: [`EXT_CARTA_PRESEED_Q2_2026.md`](../metodo_safe_gabriel/evidencia/EXT_CARTA_PRESEED_Q2_2026.md) (`CLAIM-3P` + `CAP-P14`).
