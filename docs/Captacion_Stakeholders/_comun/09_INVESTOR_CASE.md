## Tesis en una frase

Zonix Pharma es una **plataforma** que empieza resolviendo comercialización y operación de **farmacias independientes** (beachhead Valencia); Venezuela demuestra repetibilidad — no es el “mercado final” de la tesis.

## Preguntas que debes poder responder

| Pregunta | Respuesta que debes demostrar |
|---|---|
| ¿Por qué ahora? | Digitalización + presión operativa en farmacia + necesidad de canal digital local |
| ¿Quién paga? | La **farmacia** (SaaS/fee + %GMV); el paciente no es la fuente primaria del ingreso B2B |
| ¿Cómo gana dinero? | Cuota fija 45/60/70 + 8/7/5% GMV (canon pack); mix evoluciona con evidencia |
| ¿Qué prueba existe? | Cohortes Alfa/Beta, uso real, órdenes, GMV, conversión a **pago** (`FACT`) — no encuestas |
| ¿Qué dificulta copiarlo? | Datos operativos, densidad de farmacias, workflows Rx, delivery partner, aprendizaje acumulado |
| ¿Cómo escala? | Onboarding repetible + playbook comercial + expansión geo/vertical |
| ¿Qué compra el capital? | Producto, distribución, validación, métricas y runway → [`07_QUE_COMPRA_EL_ASK.md`](07_QUE_COMPRA_EL_ASK.md) |
| ¿Qué dilución ofreces? | SAFE post-money ~**15%** si aplica el cap **1.582.747** |

## Historia correcta (orden del relato)

```text
Problema → evidencia de campo → solución → wedge (farmacia) → uso →
monetización → unit economics → escala → capital → hitos → siguiente ronda
```

**Haz**

- Abrir con el problema económico de la farmacia y el beachhead.  
- Mostrar ingresos recurrentes + GMV, no solo “descargas”.  
- Vender la oportunidad de entrar **antes** de que se pruebe la escala — no el SAFE como “descuento financiero”.  
- Enlazar capital a hitos ([`07`](07_QUE_COMPRA_EL_ASK.md)).

**No hagas**

- Empezar con TAM gigante sin beachhead.  
- Decir “seremos el Amazon de farmacias”.  
- Abrir con “te vendo el 15% / el 40%”.  
- Usar claims de Café/Kleo/CrowdFarming como tracción de Zonix (`CLAIM-3P` ≠ FACT).  
- Presentar el ask como ya recaudado.
