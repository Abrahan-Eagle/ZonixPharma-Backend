## Etiquetas

| Etiqueta | Qué es | Ejemplo en esta carpeta |
|---|---|---|
| `FACT` | Hecho Zonix reproducible (mom-test, orden, pago, contrato) | **Ninguna ficha de aquí es FACT Zonix** |
| `CLAIM-3P` | Dato de tercero publicado; citar fuente + año + geo | AXXUS 420 dueños; NCPA Digest; Datia vía El Economista |
| `INFERENCE` | Conclusión nuestra a partir de CLAIM-3P | “En Valencia el dueño también pide a la droguería por WhatsApp” — **hay que confirmar en calle** |
| `GREMIAL` | Declaración de gremio, sin n muestral publicado | Fefarven 85% / márgenes |
| `SELL-IN` | Volumen de canal (labs → droguería/farmacia), no encuesta a dueño | Faro Leti 1S 2026; Cavefar/CIFAR 1S 2025 |
| `HISTÓRICO` | Estudio con *n* real pero **viejo**; no citar como “hoy” | FUNDES Lara, cooperación Mérida, gestión Táchira |
| `GEO-LARA` | Muestra Lara, no Valencia ni nacional | EE-09 |
| `GEO-MÉRIDA` | Muestra Mérida, no Valencia ni nacional | EE-15 |
| `MUESTRA-MIXTA` | El estudio incluye tipos de farmacia o públicos distintos; citar solo el bloque separable | EE-16 |
| `CAUTELA-DENOMINADOR` | Las preguntas/tablas usan bases ambiguas o inconsistentes | EE-18 |
| `LEAD` | Pista pendiente de fuente primaria, tablas o denominador | Farmacia El Terminal C.A. |
| `CONTEXT` | Fuente real útil, pero no cumple criterios para una estimación | Casos de una farmacia en Carabobo |

## Evidencia propia (campo Valencia)

Estas etiquetas **no se aplican a estudios ajenos**:

| Etiqueta | Qué demuestra | Qué no demuestra |
|---|---|---|
| `FACT-R` | Conducta reciente autorreportada y documentada | Que el relato sea exacto o represente Valencia |
| `FACT-O` | Conducta observada o registro agregado verificado | Tracción comercial por sí sola |
| `ESTIMATE` | Resultado de encuesta propia con n, método y denominador | Uso o pago de Zonix |
| `COMMITMENT` | Acción futura costosa/fechada, LOI o entrega de datos | Activación, pedido o ingreso |
| `TRACTION` | Catálogo activo, pedido real, cobro o repetición | Que una entrevista/encuesta haya validado el mercado |

## Geo

| Capa | Uso |
|---|---|
| VE | Prioridad. Con *n* hay evidencia **histórica** en Lara, Mérida y Táchira + caso Catia; reciente (2024–2026) sigue siendo gremial/sell-in. |
| LatAm (BR, MX, CO, EC, PE, BO) | Analogía operativa; no extrapolar % a Valencia |
| US (NCPA) | Gold standard de independientes; **no** pricing ni PBM como modelo VE |

**Prohibido en pitch:** “el 86% de las farmacias venezolanas anotan faltantes a mano” (eso es Brasil AXXUS).  
**Prohibido:** “el 64% de las farmacias venezolanas actuales usa software” (eso es FUNDES **Lara histórica**).  
**Permitido internamente:** “AXXUS BR 2026: 86% faltantes a mano — hipótesis a mom-test en Valencia.”

No mezclar **hospital / salud pública** con independientes (Veritas Pedernales = trabajadores de hospital; ver [`NOTA_AUDITORIA_INFORME_PYME_WORD.md`](NOTA_AUDITORIA_INFORME_PYME_WORD.md)).

## Checklist de una cita

1. Abrir la ficha y copiar **año + muestra + geo**.  
2. Confirmar rol del respondiente, denominador, página/sección y si admite respuestas múltiples.  
3. Decir si es encuesta, censo, EE.FF., gremial, sell-in o autorreporte.  
4. Registrar contradicciones internas; no escoger el porcentaje conveniente.  
5. No mezclar con ask Lean / 15% / 45-60-70.  
6. Si la URL murió → marcar ficha `STALE` y no citar fuera.

## Excluido de este corpus

Estudios de pacientes, salud pública, farmacología y **farmacia hospitalaria** presentada como retail; plantillas “cómo encuestar” (el borrador Zonix vive aparte y **no** es evidencia); claims de vendor (Fina, Extendeal “15–20%”) sin encuesta publicada; reportes de prescripción clínica; compilaciones Word/chat sin fuente primaria.
