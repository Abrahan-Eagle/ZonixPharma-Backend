# Borradores de solicitud de datos — **no enviados**

> **Estado:** borradores internos. **No contactar** sin `CAP-P09` + aprobación expresa del founder.  
> **Propósito:** obtener datos agregados, instrumentos o una invitación intermediada; **no** solicitar una base de datos personal de farmacias.  
> **Uso:** investigación del piloto Zonix Pharma en Valencia/Carabobo; no implica patrocinio, alianza ni validación de la institución.

## Qué se solicita

Prioridad:

1. Conteo agregado de farmacias activas por municipio y tipo.
2. Encuestas/tabulaciones anonimizadas a propietarios, gerentes, regentes o responsables de compras.
3. Metodología: año de campo, universo, muestra, tasa de respuesta, cuestionario y denominadores.
4. Acceso a tesis, anexos o tablas no digitalizadas.
5. Opcional: difusión intermediada de una invitación a estudio; la institución conserva los contactos.

No pedir:

- nombres, cédulas, teléfonos personales ni correos masivos;
- recetas, datos de pacientes o información de salud;
- información comercial individual (ventas, margen, impuestos) sin consentimiento;
- respaldo público, logo o carta de alianza antes de un acuerdo formal.

## Diccionario mínimo para evaluar una respuesta

| Campo | Por qué importa |
|---|---|
| Fecha de campo/publicación | Evitar presentar histórico como 2026 |
| Geografía | Separar Valencia, Carabobo y nacional |
| Universo y marco | Saber quién podía ser seleccionado |
| Establecimientos únicos / RIF | Evitar duplicar sucursales |
| Rol del respondiente | Dueño ≠ administrador ≠ regente |
| n invitado / n válido / tasa | Medir sesgo de no respuesta |
| Instrumento | Ver pregunta exacta |
| Resultado + denominador | Evitar porcentajes huérfanos |
| Independiente/cadena | No fusionar modelos operativos |
| Permiso de uso | Citar sin atribución indebida |
