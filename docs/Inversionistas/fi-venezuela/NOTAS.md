## Equity Collective (flujo)

1. Apply + Entrance Fee → solo **Entrance Agreement** para empezar.
2. ~**2/3** del Core → firma **Warrant 2,5%** (por compañía, no por founder).
3. Activación en primera **Qualified Equity Financing**: equity externo ≥**USD 100k** (o ≥**USD 25k** si luego programa calificado tipo YC).
4. Salida sin Collective: ≥45 días antes de Graduation (FAQ).
5. **Vs ALGEN:** ALGEN = 0% programa; FI = fee + posible 2,5%.
