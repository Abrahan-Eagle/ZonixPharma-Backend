## A. Founder's Playbook AI-Native (FP)

**Identidad:** playbook ciclo startup 2026; framing “AI-native / agentic coding”.

### KEEP (síntesis jueces FP-1/FP-2)

| Tema | Claim operativo | Origen |
|------|-----------------|--------|
| Idea stage | No construir hasta evidencia; problem-solution fit; hipótesis testable | p8–13 |
| Discovery | Preguntar comportamiento pasado; síntesis evidencia a favor/contra | p12–13 |
| Anti-falsos | Prototipo ≠ validación; premature scaling; confirmation bias | p9–10 |
| MVP / PMF | Retención, revenue, referral; false PMF de launch | p15–18 |
| Medición | Framework **antes** del primer usuario; Sean Ellis ~40%; push→pull | p19 |
| Launch gates | Compliance continuo; ops sin cuello founder; no expandir geografía prematura | p21–24 |
| Security | Review antes de usuarios reales (crítico Rx/datos) | p17–18 |

### DROP

- Founder sin código shipando producción; orquestador de agentes; agentic coding como sustituto de equipo.
- Scale: millones usuarios, IPO, Wall Street, Anthropic/YC credits, tooling Claude como canon.

### Prohibido en pitch

Narrativa “somos AI-native startup” como moat. Zonix = marketplace pharma VE con stack ya construido; foco = evidencia mercado Valencia.
