# Aprendizaje 500 — evidencia de mercado (pack inversores)

> **Última actualización:** 7 agosto 2026  
> **Propósito:** lección canónica para el pack Lanzamiento tras el rechazo de 500 LatAm.  
> **No es asesoría legal ni financiera.** CRM detalle: [`../Inversionistas/500-latam/`](../Inversionistas/500-latam/).

## Qué pasó

El 6 agosto 2026, **500 Global / 500 LatAm** rechazó la aplicación de Zonix Pharma. Motivo declarado: la startup **carece de un MVP o demo funcional** a sus ojos. Invitan a recontactar `team-mx@500startups.com` cuando haya **producto en el mercado**.

## Qué significa para el pack

| Concepto | Qué es | Qué no es |
|----------|--------|-----------|
| MVP técnico | Staging, API Rx, Flutter, cientos de tests | Lo que 500 midió en el apply |
| Evidencia de mercado | Demo 3–5 min + early adopters (farmacias/pedidos) | Solo slides o “443 tests” |
| Ask Lean | **USD 237.412** SAFE cap 600k | Cheque 500 (285k neto) — otro ciclo |

**Mensaje canónico:** stack/staging = capacidad. Para fondos tipo 500 (y para credibilidad general) hace falta **demo consumible + adopción temprana**.

## Implicaciones operativas (docs)

1. Checklist pre-inversor exige demo producto + métrica de tracción piloto ([CHECKLIST_PRE_INVERSOR.md](CHECKLIST_PRE_INVERSOR.md)).  
2. Pitch honesto: pre-revenue; staging hoy; piloto Valencia en curso ([BRIEF_UNA_PAGINA.md](BRIEF_UNA_PAGINA.md), [MENSAJE_ENVIO_Y_BULLETS_INVERSIONISTA.md](MENSAJE_ENVIO_Y_BULLETS_INVERSIONISTA.md)).  
3. Freeze de alcance en narrativa: no vender 20 features; vender happy path + beachhead ([CONTEXTO_PITCH_Y_DECISIONES.md](CONTEXTO_PITCH_Y_DECISIONES.md)).  
4. Plan A caja: **Epakon / Casa212 / ALGEN**. 500 = nurture post-gate.

## Qué no hacer

- Mentir “ya en mercado” sin farmacias/pedidos.  
- Priorizar Platzi / User on board / perks del email 500.  
- Construir más módulos “porque pidieron MVP”.  
- Meter el CRM `Inversionistas/` completo en el zip al LP.
