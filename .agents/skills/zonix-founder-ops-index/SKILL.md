# zonix-founder-ops-index

Índice de lectura para **founder / CTO** en Zonix Pharma. Fuentes principales: [awesome-ceo](https://github.com/kuchin/awesome-ceo), [awesome-cto](https://github.com/kuchin/awesome-cto), [awesome-tpm](https://github.com/kuchin/awesome-tpm).

**No sustituye** las skills operativas: `zonix-launch-piloto`, `zonix-fundraising-narrative`, `zonix-empresa-ve`.

## Cuándo usar este índice

| Situación | Leer primero (externo) | Skill Zonix después |
|-----------|------------------------|---------------------|
| Preparar ronda pre-seed | awesome-ceo → Fundraising | `zonix-fundraising-narrative` |
| Primeros 90 días post-wire | awesome-cto → «Your first 90 days» | `zonix-launch-piloto` |
| Due diligence técnica inversor | awesome-cto → Due diligence | `zonix-investor-materials` + tests repo |
| Crisis / runway | awesome-ceo → Adapting to Endure (Sequoia) | `zonix-financial-model` PROYECCION §7 |
| Contratar y escalar equipo | awesome-ceo → Hiring; awesome-cto → Hiring | `zonix-lanzamiento-roles` |
| Coordinar hitos multi-equipo | awesome-tpm | `zonix-launch-piloto` |
